# Photos

Drop real clinic photos here. Keep originals; the build pipeline makes the
web sizes. Suggested folders: `exterior/`, `reception/`, `rooms/`, `team/`,
`doctors/` (one file per dentist, named by slug), `equipment/`, `testimonials/`.

Shot list for a new session (phase 1 delivers the full Persian list):
exterior with the sign, reception with staff, waiting area, each treatment
room, sterilization area, each dentist at work and as a portrait, hands with
tools, the scanner or digital workflow in use, happy patient at the end of a
visit (with consent), details that feel calm (plants, light, textures).

Rules: no AI-generated or stock people. Faces look toward the lens or the
content. Natural, warm light. Landscape and portrait of every scene.
