# Keyword Map

One row per indexable URL in `docs/ia.md`. Search volumes are **unknown**:
no keyword tool was reachable from this environment and nothing is
estimated. Validate in phase 6 with Google Search Console data (after launch)
or a keyword tool the client can access.

Conventions:

- Title pattern: `{topic} | کلینیک دندانپزشکی سفید`; the topic part stays
  under about 35 characters so the whole title stays near 50-60. Phase 6's
  admin validator enforces length.
- H1 is the visible headline; it carries the primary term naturally.
- Intent codes: **N** navigational, **L** local, **C** commercial
  (comparing, about to choose), **I** informational, **T** transactional.
- "(verify)" marks a term that implies a capability the client has not
  confirmed yet. Do not use it in copy until confirmed.

google.com in Tehran): local queries for خانی‌آباد returned doctor
directories (nobat.ir, doctoreto.com) and Balad listings, and no clinic
website. The brand name returned nothing. Directories are the real local
competitors in the results; a complete profile on each is a cheap citation
and a second booking channel.
